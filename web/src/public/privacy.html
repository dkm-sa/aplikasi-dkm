Dewan Kemakmuran Masjid

Kebijakan Privasi Aplikasi DKM

Terakhir diperbarui: 21 Oktober 2026

Aplikasi DKM adalah aplikasi desktop Windows untuk membantu pengurus Dewan Kemakmuran Masjid (DKM) mengelola kas, data jamaah, inventaris, surat, dan dokumen organisasi. Halaman ini menjelaskan bagaimana aplikasi menangani data Anda.

Data yang disimpan

Semua data aplikasi (transaksi kas, data jamaah dan donatur, surat, foto, dan pengaturan) disimpan di komputer Anda sendiri. Kami tidak memiliki server dan tidak mengumpulkan, menjual, atau membagikan data Anda kepada pihak mana pun.

Google Drive

Jika Anda memilih fitur "Masuk dengan Google" untuk backup, aplikasi meminta izin drive.file. Dengan izin ini aplikasi hanya dapat membuat dan mengakses file backup yang dibuatnya sendiri di Google Drive Anda. Aplikasi tidak dapat melihat, membaca, atau mengubah file lain di Drive Anda.

Token akses Google disimpan hanya di komputer Anda dan dipakai semata-mata untuk mengunggah dan mengunduh file backup. Anda dapat memutus akses kapan saja melalui menu Backup di aplikasi atau di halaman Izin Akun Google.

Penggunaan informasi yang diterima dari Google API mematuhi Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Penggunaan Terbatas (Limited Use).

Penghapusan data

Anda dapat menghapus data dengan menghapus folder data aplikasi di komputer Anda serta file backup di Google Drive Anda.
